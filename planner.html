Personal productivity project

Schedule HQ.

A study planner designed around my school routine, exam dates and chapter-level goals — with a ChatGPT-powered study assistant planned through a secure server backend.

View project on GitHub ↗Personal website

What it includes

  • Weekly calendar and editable daily checklist
  • Live clock and current-task indicator
  • Exam countdowns and chapter/subtopic progress
  • Study-session tracking and daily reflections
  • Light and dark themes
  • AI assistant integration package with server-side API key handling

AI connection status

The AI interface and Node.js backend are prepared in the separate Schedule HQ AI package. To use live AI, deploy the backend on a Node.js host and configure the OpenAI API key as a server environment variable. The key must never be placed in this static website.

This page is a project overview, not the live planner application. The planner's personal progress data remains in the browser unless a separate sync service is configured.
